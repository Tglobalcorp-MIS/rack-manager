# T1 機房機櫃管理（rack-manager）

T1 機房 A、B 兩座 42U 機櫃的擬真管理網頁。單一 `index.html`，不需要建置或安裝套件，直接用瀏覽器開啟即可。

線上版（Claude Artifact，資料雲端共用）：https://claude.ai/artifact/5p8KW2Y24i7GeSQdavmBpL

## 功能

- 擬真機櫃外觀：機櫃立柱、每 U 三孔的 EIA 導軌、U 數刻度、HPE／Dell／Supermicro／Forti 等設備面板、黃色標籤貼紙
- 2D 模式滾輪以滑鼠位置為中心縮放，拖曳空白處平移畫面
- 2D／3D 任意切換：3D 模式中兩座機櫃是有側板、頂板的立體箱體，滑鼠拖曳旋轉、右鍵或 Shift 拖曳平移、滾輪縮放（觸控可單指旋轉、雙指縮放），另有自動旋轉與重設視角
- 正面／背面切換（背面為由後方看的鏡像位置）
- 2D 模式下拖曳設備上下移動或跨機櫃移動，放下前即時顯示可放置（綠）或衝突（紅）；3D 模式下用右側位置控制或方向鍵移動
- 調整位置：上下（U 位）、前後（前側／後側／前後全深）、左右（滿寬／左半／右半），以及「反向安裝」
- 點擊設備開啟「完整資料卡」：網路、系統與規格、資產與保固、管理與負責人、電源等欄位，空白欄位標示「待填寫」，點一下即可編輯，並顯示資料完整度與保固到期提醒
- 網路拓樸：依外部線路、防火牆、核心交換器、交換器、伺服器與終端分層顯示，可新增／編輯連線（網路線、光纖、FC、電源、Console，含兩端埠口與速率），節點可拖曳、畫面可平移縮放，線上有封包流動動畫
- 設備關聯：選取設備時，機櫃中與它有連線的設備會以青色外框標示；資料卡列出所有連線
- 「產生連線草稿」可依機櫃擺設推測常見連線，全部標為「待確認」，交由專責人員核對
- 新增、複製、刪除設備；點空的 U 位可直接在該位置新增
- 動畫：開機指示燈依序亮起、硬碟與網路埠閃爍、螢幕捲動、機櫃門開關、熱力分布
- 設備狀態：運作中（狀態燈綠色呼吸）、維護中（黃燈慢閃、風扇加速）、告警／異常（紅燈快閃、風扇全速）、關機
- 「待處理」清單：告警、維護中、保固已過期或 90 天內到期的設備，以及 IP／序號／負責人缺漏統計
- 彩蛋：A 機櫃頂上的綠色乖乖
- 搜尋（名稱／型號／IP）、類型篩選、設備清單、空位統計、異動紀錄、復原（Ctrl+Z）
- 匯出 Excel（CSV，含所有資料欄位）
- 匯出／匯入 JSON 備份，可一鍵重設為原始盤點

## 鍵盤快速鍵

| 按鍵 | 動作 |
| --- | --- |
| ↑ ↓ | 上下移動 1U |
| ← → | 移到左邊／右邊的機櫃 |
| Shift + ← → | 半寬設備靠左／靠右 |
| F | 切換安裝面 |
| V | 翻轉正面／背面 |
| Delete | 刪除 |
| Ctrl + Z | 復原 |

## 資料儲存

- 在 Claude Artifact 中開啟時，資料存在 Artifact 的雲端資料庫（文件 `racks/t1`，含 devices、links、topo），有權限的人看到同一份並即時同步。
- 直接開啟本儲存庫的 `index.html` 時，資料只存在該瀏覽器（localStorage）。
- `data/t1-initial.json` 是 2026/10/16 現場盤點的 45 筆設備，可用頁面上的「匯入」載入。

## 盤點備註

- B 機櫃 9U 原始清單寫作「Profrt AI」，照片上的標籤是 Profet AI，網頁採用 Profet AI。
- A 機櫃機櫃風扇原始記為「42.3」，42U 機櫃最高只有 42U，因此放在 42U。
- 「13U 後面有排插」「25U 後有小烏龜」以後側安裝的獨立設備表示。
- 部分型號（HPE MSA 2060 FC、IBM System x3250 M3、Server Farm Switch 的 IP 192.168.1.4）是依照片標籤判讀。
